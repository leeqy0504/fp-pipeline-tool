页面清单

1. 登录页

输入全局密码，session cookie 维持登录。无注册、无用户管理。

2. 任务面板（首页）

列出所有 task，每个显示 5 阶段状态指示灯。点击进入任务详情。新建任务按钮。

3. 任务详情 / Pipeline 调度

选中一个 task，显示 5 阶段进度条 + 实时日志终端 + 启动/重跑/停止按钮。每个 stage 可单独触发。

4. 上传页

拖拽/选择本地文件夹上传到服务器 tasks 目录。显示上传进度。上传完自动识别为可运行 task。

5. 配置编辑器

在线编辑 config YAML。语法高亮 + 格式校验。保存后下次 run 生效。列出 configs/ 下所有配置文件。

6. 历史日志

查看已完成任务的每次运行日志。按 task 和时间筛选。日志回放（类似 CI/CD log viewer）。
